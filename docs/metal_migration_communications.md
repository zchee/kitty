# Communication Plan for Metal Migration (2025-11-03)

## Stakeholder Touchpoints
- Weekly engineering sync (project lead, renderer, shader, tooling, QA).
- Bi-weekly product/PM update reviewing milestone progress and risks.
- Monthly community update highlighting progress and soliciting feedback.

## Channels
- Internal: Slack #metal-migration channel, project tracker, weekly status email.
- Community: Release notes, blog posts, social media announcements, mailing list.
- Support: Knowledge base articles, FAQ updates, issue tracker templates.

## Key Messages
- Rationale for Metal migration (OpenGL deprecation, performance, future-proofing).
- Expected timeline and phases (prototype, beta, stable, OpenGL deprecation).
- How users can opt-in/out, provide feedback, and report issues.

## Timeline
- Announce project kickoff before Milestone M1 completion.
- Publish progress blog post after M2 (text rendering) milestone.
- Share beta invitation details when entering Phase 1 (dual support).
- Provide clear deprecation notices with at least two release cycles lead time.

## Feedback & Support Loop
- Create dedicated feedback form for Metal beta participants.
- Track high-priority issues in public tracker with Metal label.
- Provide ETA updates for critical bug fixes in community forums.
